# Design Document: AI Learning Assistant
## AWS AI Bharat Hackathon 2026

## Overview

The AI Learning Assistant is a production-ready, cloud-native learning platform built on AWS. It delivers personalised AI-powered education to students and developers across India through **18 features**, all backed by real AWS services — zero demo modes, zero static responses.

**Stack:** FastAPI (Python) backend on Elastic Beanstalk · Next.js 14 App Router frontend on Vercel · Amazon Bedrock Nova Pro as the AI brain · DynamoDB for persistence · Cognito for auth

## AWS Services Used

| Service | Purpose |
|---|---|
| **Amazon Bedrock (Nova Pro)** | All AI generation — tutor, quiz, flashcards, code analysis, study paths, translation, interview prep |
| **Amazon Bedrock (Claude 3.5 Sonnet v2)** | Vision tasks — handwriting OCR, diagram analysis, math solving |
| **Amazon DynamoDB** | Sessions, quiz results, user progress, learning goals, study rooms |
| **Amazon Cognito** | Authentication — Google OAuth + username/password + guest mode |
| **Amazon SNS** | Achievement notifications (level-ups, badges) |
| **Amazon S3** | Content uploads (PDFs, images) |
| **Amazon Polly** | Text-to-speech for voice interface |
| **Amazon Transcribe** | Speech-to-text |
| **Amazon Translate** | Fallback translation support |
| **Amazon Comprehend** | Language detection, NLP |
| **Elastic Beanstalk** | Backend hosting — auto-scaling Python FastAPI |
| **Vercel** | Frontend hosting — Next.js 14 SSR/SSG |

## Features (18 Total)

### 1. AI Tutor with Socratic Method
Real conversational tutoring via Amazon Bedrock Nova Pro. Sessions persisted to DynamoDB. Supports Socratic, direct, and exploratory teaching styles. Full multilingual response in 14 Indian languages.

### 2. AI Study Buddy (Nova — "Goal Buddy")
Chat with an adaptive AI companion. Create AI-generated learning goals with milestone breakdowns. Start adaptive study sessions with personalised 30-min plans.

### 3. Smart Study Path Generator
Enter topic + current level + target level → receive a full skill gap analysis, module-by-module learning path with resources, and a weekly schedule. 100% generated by Bedrock Nova Pro.

### 4. Quiz Generator
Generate 3–15 multiple-choice, true/false, or fill-in-blank questions from any text. Results stored in DynamoDB. XP awarded on submission via the Gamification system.

### 5. Flashcard Generator (Spaced Repetition)
Generate up to 20 flashcards from any content with flip animations. Difficulty levels assigned by AI. Spaced repetition data model ready.

### 6. Code Analyzer
Deep code analysis: line-by-line explanation, complexity metrics, issues detection (with severity), improvement suggestions with before/after code. Supports Python, JS, TS, Java, C++, Go, Rust.

### 7. Interactive Code Playground
Real Python execution in a restricted sandbox. Non-Python languages: AI simulates expected output and explains the code. Input injection supported. AI suggestions on every run.

### 8. Multimodal AI Processor
Upload images for: Handwriting OCR · Diagram understanding · Math problem solving · Screenshot-to-quiz. Powered by Claude 3.5 Sonnet v2 vision.

### 9. Interview Prep *(NEW)*
Generate 8 role-specific interview questions (technical, behavioral, system design) for any job and company. Practice mode with AI evaluation: score out of 100, strengths, improvements, model answer, verdict.

### 10. Content Summarizer *(NEW)*
Paste any text — lecture notes, articles, docs — and get: Brief / Detailed / Bullet Points / Hierarchical summaries + 5 key takeaways. One-click copy.

### 11. Multilingual Translation *(NEW)*
Translate educational content into 15 Indian languages including Hinglish and Tanglish (code-mixed). Real-time via Bedrock Nova Pro with educational context preservation.

### 12. Collaborative Learning Rooms
Create or join AI-moderated study rooms. Rooms persisted to DynamoDB. AI generates tags on creation and a personalised welcome message on join. AI moderator analyses messages and injects insights.

### 13. Gamification System
XP, 100+ levels, 50+ achievements, badge tiers (Bronze → Diamond). DynamoDB-backed. SNS notifications for unlocks. Leaderboards.

### 14. Study Timer (Pomodoro)
25/5-minute Pomodoro cycles with browser notifications. Session tracking.

### 15. Progress Tracker
Track custom learning goals with progress bars. Persisted to localStorage with export.

### 16. Study Notes
Rich note-taking with voice input, search, categories, pin, export as Markdown.

### 17. Voice Interface
Web Speech API integration for voice input on tutor, quiz, notes, flashcard generator. Inline microphone with live transcript preview.

### 18. Authentication (AWS Cognito)
Google OAuth via Cognito Hosted UI · Username/password via Cognito user pools · Guest mode for instant demo access.

## Frontend Design System

- **Framework:** Next.js 14 App Router — all components `'use client'`
- **Styling:** Pure CSS custom properties — glassmorphism aesthetic
  - Layered dark backgrounds (`#02020a` → `#1a1a40`)
  - `backdrop-filter: blur(20–40px)` glass panels
  - Indigo/violet/cyan gradient palette with glow effects
  - `box-shadow` glow layers for interactive elements
  - Animated background mesh gradients
  - CSS grid overlay for depth
  - Scan-line animation
- **Typography:** Plus Jakarta Sans (body) · Sora (display/headings) · JetBrains Mono (code)
- **Animations:** Framer Motion — page transitions, staggered entry, hover/tap spring physics
- **Responsive:** Mobile-first with CSS grid/flex, collapsing nav at 768px
